- **Live platform status** — the portfolio pings thepeoplesregister.co.za from the visitor's browser
- **Live Core Web Vitals** — LCP / CLS / INP measured on the page itself via PerformanceObserver
- **Trilingual UI** — full EN / isiXhosa / Afrikaans localisation engine, dictionary-level, persisted
- **Command palette** — keyboard-first navigation (⌘K / Ctrl+K / `/`)
- **Zero dependencies** — one file, no framework, no CDN, no trackers, no cookies
